## Qué puede estar pasando

- La conexión a internet del usuario es lenta o inestable.
- Hay muchos usuarios a la vez: horas punta, cierres de mes, matrículas o exámenes.
- Se está ejecutando un proceso pesado, como un reporte muy grande o una carga masiva de datos.
- El servidor tiene poca capacidad para el uso actual o la base de datos necesita mantenimiento.
- El navegador tiene muchas pestañas o extensiones abiertas.

## Qué puedes probar

1. Comprueba tu velocidad de internet o prueba desde otra red.
2. Cierra pestañas que no uses y prueba en una ventana privada.
3. Fíjate si es lento todo o solo una pantalla o acción concreta.
4. Si sueles generar reportes grandes, prueba a acotar las fechas o hazlo fuera de las horas de más uso.
5. Anota la hora a la que notas la lentitud.

## Cuándo avisar a CONIT

- Si es lento para todos los usuarios, desde cualquier red.
- Si una pantalla tarda más de un minuto o termina en un error de tiempo agotado.
- Si empeoró de golpe tras un cambio o una actualización.

## Qué datos enviarnos

- Qué pantalla o acción va lenta y cuánto tarda aproximadamente.
- A qué hora ocurre y si es siempre o solo a ratos.
- Cuántas personas están afectadas.
