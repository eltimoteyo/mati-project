## Qué puede estar pasando

- La sesión caducó porque pasó mucho tiempo sin actividad.
- Falta un campo obligatorio o un dato tiene un formato no válido (fechas, números, DNI o RUC).
- El archivo adjunto es demasiado grande o de un tipo no permitido.
- Hay un error interno del sistema, a menudo después de una actualización ("Error 500" o una pantalla en blanco).
- La conexión se cortó justo al enviar.

## Qué puedes probar

1. Antes de recargar, copia lo que escribiste para no perderlo.
2. Cierra sesión, vuelve a entrar e inténtalo de nuevo.
3. Revisa los campos marcados en rojo y el formato de fechas, números y documentos.
4. Si adjuntas un archivo, prueba con uno más ligero o en otro formato (por ejemplo, PDF).
5. Anota el mensaje exacto que aparece.

## Cuándo avisar a CONIT

- Si el error se repite después de volver a entrar.
- Si aparece "Error 500", "Error interno" o una pantalla en blanco.
- Si les pasa a varios usuarios.

## Qué datos enviarnos

- La pantalla o módulo y qué intentabas guardar.
- El mensaje exacto o una captura de pantalla.
- La hora aproximada y tu usuario.
