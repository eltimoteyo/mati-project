## Qué puede estar pasando

- Un problema de tu conexión o de tu navegador (por ejemplo, una versión antigua guardada en la caché).
- El servidor o el hosting está caído o saturado.
- El dominio venció o su configuración (DNS) cambió.
- El certificado de seguridad (SSL) venció, y el navegador avisa de que la conexión no es segura.
- Un error en la propia web, a menudo después de una actualización (por ejemplo, "Error 500").

## Qué puedes probar

1. Abre la web desde otra red, por ejemplo con los datos del celular, y desde otro navegador o una ventana privada.
2. Recarga forzando la actualización: Ctrl + F5 en Windows o Cmd + Mayús + R en Mac.
3. Comprueba si otras webs cargan con normalidad desde tu equipo.
4. Anota el mensaje exacto que aparece: "Error 500", "404", "No se puede acceder a este sitio", "La conexión no es privada"...
5. Revisa si recibiste algún aviso de vencimiento del dominio o del hosting.

## Cuándo avisar a CONIT

- Si no carga desde ninguna red ni dispositivo.
- Si aparece "Error 500", "503" u otro error del servidor.
- Si el navegador dice que el certificado no es válido.
- Si sospechas que el dominio o el hosting vencieron.

## Qué datos enviarnos

- La dirección exacta de la web o de la página que falla.
- El mensaje de error o una captura de pantalla.
- Desde cuándo pasa y si falla toda la web o solo una página.
