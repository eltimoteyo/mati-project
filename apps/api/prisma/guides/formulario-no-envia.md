## Comprobación inicial

Pide URL del formulario, hora de prueba y error visible. Sugiere una sola prueba con datos ficticios no sensibles. Revisa disponibilidad de la web y guía de correo. Si el formulario acepta pero no entrega, deriva con el horario y el resultado.

## Traspaso al equipo

Registra síntoma, servicio, alcance, comprobaciones y pasos ya probados. Pide confirmación y horario de contacto, salvo urgencia. Esta guía debe revisarse y publicarse desde la base de conocimiento antes de que la utilice la IA.
